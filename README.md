# Classificação de calçados
Dataset de imagens (.png e .jpg) de calçados estruturado para projetos de Machine Learning e Visão Computacional.

## Origem dos dados: 
As imagens foram extraídas do repositório **Sneakers Image Dataset Pinterest**, no Kaggle, e passaram em processo de limpeza de dados.

## Estrutura do projeto:
- `dataset_botas/`: imagens utilizadas para classe de botas.
- `dataset_tenis/`: imagens utilizadas para classe de tênis.
